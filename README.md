# 🛡️ Cyber Defender

A cyberpunk-style browser game where you defend a network from incoming cyber threats.

## 🎮 Game Overview

Cyber Defender is a simple interactive web game built with HTML, CSS, and JavaScript.

Your mission is to survive for 30 seconds while eliminating incoming cyber threats.

## ✨ Features

- 🎮 Interactive Start Screen
- ⚠️ Cyber Threats
- ⏱️ 30-second Timer
- ❤️ 3 Lives
- 🏆 High Score System
- 🔊 Sound Effects
- 🎯 Achievement System
- 🔥 Combo System
- 💀 Cyber Master Achievement
- 📈 Dynamic Difficulty
- 🟢 Easy → Medium → Hard
- 🏆 Victory Screen
- 💀 Game Over Screen
- 🌃 Cyberpunk UI

## 🏅 Achievements

| Achievement | Requirement |
|---|---|
| 🎯 First Hit | Hit your first threat |
| 🔥 Combo 5 | Reach 5 points |
| 💀 Cyber Master | Reach 10 points |

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Audio API

## 🚀 How to Play

1. Click **START GAME**
2. Click the ⚠️ threats before they disappear
3. Avoid losing all 3 lives
4. Try to reach 10 points
5. Survive the full 30 seconds

## 🎯 Goal

Survive the cyber attack and achieve the highest score possible.
